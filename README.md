# M3 Memory Archive

The M3 Memory Archive is a private-first system for collecting, reviewing, and organizing memories of MOFUNDO through the people who were there.

## V1 journey

`QR link -> tell the story -> upload evidence -> choose permissions -> submit -> private review -> approve or archive`

Nothing submitted becomes public automatically.

## Project status

This repository starts with the V1 product contract and database architecture. The application is built with Next.js, TypeScript, and Supabase/Postgres.

See:

- `docs/V1_SPEC.md` for the user and administrator experience
- `docs/DATA_MODEL.md` for the entity model
- `supabase/migrations/0001_initial_archive.sql` for the authoritative schema and security policies
