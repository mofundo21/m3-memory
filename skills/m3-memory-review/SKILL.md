# M3 Memory Review

Keep these layers distinct:

- Contributor memory
- Yeriel memory / notes
- AI observation
- Confirmed evidence

Do not merge these layers in prose, UI, database changes, exports, or prompts.

When reviewing a memory, label what is source material, what is Yeriel commentary, what is AI interpretation, and what has independent evidence.
