# M3 Evidence Check

Compare:

- contributor submissions
- dates
- locations
- media
- other contributors
- Yeriel notes

Identify:

- corroboration
- contradictions
- uncertainty
- missing information

Never fabricate a resolution. Flag conflicts and uncertainty explicitly.
