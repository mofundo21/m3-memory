# M3 Memory Archive

Contributor submissions are immutable historical source records.

Rules:

- Original submissions must never be silently rewritten.
- Corrections belong in separate review records.
- AI interpretation belongs in separate records.
- AI-generated prose is never historical evidence.
- Conflicts must be flagged, not silently resolved.
- Preserve timestamps and provenance.
- Never delete historical records casually.

Do not remove necessary security, accessibility, validation, backups, tests, error handling, or historical data integrity controls.
